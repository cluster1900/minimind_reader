## 发现与修订

1. **损失归约符号含混。** 第 12 章先用 `mean_mask` 表示 PPO 的小批有效 token 均值，又在 CISPO 式中使用同名符号，
   尽管后文提到按回答平均，读者仍可能代入错误分母。现改为显式的 token 分母和“每条回答有效长度 → 回答总数”两层分母，
   补齐回答/位置下标及空回答行的处理。真实 `grpo_train_epoch` 归约语句的新实验得到回答均值 2、全 token 均值 2.5；
   反向梯度分别为 0.5 和三个 1/6，mask 位置为零。
2. **图中关键依赖省略。** 图 9-1 增加 Top-K 选择频率到辅助损失的边；图 17-1 明确在指定 block 保存 Bridge，
   后续 Thinker 与 Talker 从此分叉，不能把后续 Thinker 的状态倒流为 Bridge。对应 MoE 与 Bridge 实验分别检查数值和梯度路径。
   图 18-1 加入任一路达到停止位置时音频帧为 None 的分支。
3. **VAD 图的层次不清。** 图 20-2 改成输入检测状态图，将 generating 作为外部条件，终点仅表示返回打断事件。
   状态转移与 `RealtimeSession.push_chunk` 的开始/结束阈值、提前返回及会话消费者职责逐项核对。
4. **长公式在手机上整体缩小。** 将并排的矩阵、损失定义、频率/码本换算及奖励统计拆为多行 Markdown 数学。
   其余较长的等式链和 DPO 差值也分行；保留运算方向、求和范围、符号和语义说明，不把公式改成截图或普通文本。
5. **历史基线被当前 HEAD 误伤。** 原校验器要求 HEAD 等于引用 commit，且符号从当前工作区解析。
   现在统一用 `git show <完整 commit>:<路径>` 检查源代码，支持当前 HEAD 和工作区已变化、而旧引用仍可重建的情况。
   不切分支、不修改上游、不自动迁移章节版本；数值实验仍要求显式准备匹配的工作区。
6. **复核状态不能持续约束修改。** 新增正文、全部行内/块公式、所有 Mermaid 图及固定源文件的审阅快照。
   发行构建与最终复制均检查快照，公式、箭头、说明或引用基线改变后，旧复核记录不再通过。
   这只是检测“复核之后发生了变化”，不把哈希检查说成自动证明数学与源码语义正确。
7. **结构约定缺少固定检查。** 新增前置依赖无环、验证记录存在、章节元信息与源码映射版本一致等检查。
   新增反例测试：改公式、反转图箭头、改说明、改源快照、加入未审阅文档、依赖环和未知前置章都必须失败。
