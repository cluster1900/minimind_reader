# 全书术语表

这张表用于阅读时快速回查，不要求开始前背诵。相近词放在同一组比较，
第一次遇到某个概念时仍应返回对应章节的小例子和源码解释。词条随各篇章逐步补齐。

## 数据与计算

| 术语 | 通俗解释 | 首次主讲 |
|---|---|---|
| token / 词元 | 模型处理的编码单位，未必是完整字或词 | 02 |
| token ID | token 在词表中的编号，用于索引向量；编号大小不是重要性 | 01～02 |
| tokenizer / 分词器 | 在文字与 ID 序列之间转换的组件 | 02 |
| BPE / 字节对编码 | Byte Pair Encoding；从小符号出发，按语料统计学习相邻合并的一类分词方法 | 02 |
| chat template / 聊天模板 | 把角色、正文和结构标记组织成实际输入字符串 | 02 |
| BOS、EOS、PAD | 开始、结束、补齐相关标记；是否插入及如何使用由具体路径决定 | 02、06 |
| tensor / 张量 | 带形状、数值类型和设备的多维数组 | 01 |
| shape / 形状 | 每个轴的长度；形状相容不代表轴的语义正确 | 01 |
| dtype / 数值类型 | 例如整数、FP32、FP16、BF16，决定表示方式与数值范围等 | 01、03 |
| device / 设备 | 张量或计算所在的 CPU、GPU 等位置 | 01 |
| broadcasting / 广播 | 沿相容的长度为 1 的轴复用数值，不是拼接内容 | 01 |
| parameter / 参数 | 可学习的模型数值，如投影权重与归一化缩放 | 01、03 |
| activation / 激活 | 当前输入计算得到的中间结果，不同于持久参数 | 03 |
| forward / 前向 | 用当前参数和输入计算输出 | 01 |
| backward / 反向 | 沿计算关系求梯度，不自动等于更新参数 | 01、07 |
| gradient / 梯度 | 参数局部变化怎样影响目标的导数信息 | 01 |

## 模型与生成

| 术语 | 通俗解释 | 首次主讲 |
|---|---|---|
| Embedding | 根据 ID 取出对应可学习向量的表 | 03 |
| hidden state / 隐藏状态 | 模型内部为各位置维护的表征向量，可以检查其数值和形状 | 03 |
| Linear / 线性层 | 按可学习权重组合输入特征，通常改变最后一维 | 01、03 |
| residual / 残差连接 | 在输入上加一项修正，两个分支必须形状相容 | 03 |
| RMSNorm / 均方根归一化 | Root Mean Square Normalization；按均方根尺度归一化再乘可学习权重，不做均值中心化 | 03 |
| SwiGLU | 一条 SiLU 门控分支与内容分支相乘，再投影回去的前馈结构 | 03 |
| weight tying / 权重共享 | 多处计算引用同一份参数，不只是数值恰好相同 | 03 |
| Q、K、V | 用于匹配的查询、候选键，以及被加权汇总的值 | 04 |
| attention head / 注意力头 | 注意力中的一组特征子空间与对应匹配计算 | 04 |
| GQA / 分组查询注意力 | Grouped Query Attention；多个查询头共用一组 K/V 的布局 | 04 |
| causal mask / 因果掩码 | 不允许当前位置参考未来位置 | 04 |
| padding mask | 标记无效键位置；不自动清空对应 query 输出 | 04 |
| SDPA / 缩放点积注意力 | Scaled Dot Product Attention；PyTorch 的缩放点积注意力 API；API 名称不等于一次确定的 GPU 内核 | 04 |
| RoPE / 旋转位置编码 | Rotary Position Embedding；通过按位置旋转 Q/K，让相对位置关系进入匹配 | 05 |
| KV Cache | 保存历史位置的 K/V，供后续推理复用 | 05 |
| prefill / 预填充 | 首次处理 prompt，并形成初始缓存 | 05 |
| decode / 解码阶段 | 用新 token 和历史缓存继续生成；与 tokenizer 的 decode 需看上下文区分 | 02、05 |
| logits | 输出头给各候选的未归一化分数，尚不是概率 | 03 |
| softmax | 把一组分数变成和为 1 的正权重；必须说明归一化轴 | 04 |
| temperature / 温度 | 生成时调整 logits 相对差异的参数，本实现应为正数 | 05 |
| Top-K、Top-P | 分别按分数阈值或累计概率前缀筛选候选 | 05 |

## 训练与评估

| 术语 | 通俗解释 | 首次主讲 |
|---|---|---|
| Dataset | 定义一条记录怎样变成训练张量 | 06 |
| DataLoader | 迭代、组织一批样本的工具 | 06～07 |
| labels / 目标标签 | 用来与预测对齐的目标；-100 可表示忽略该目标 | 06 |
| shift / 错位 | 让前一位置的输出对应后一位置的目标，需避免重复做 | 06 |
| loss / 损失 | 本次优化目标的数值；必须注明包含哪些项 | 06～07 |
| NLL / 负对数似然 | 对正确目标概率取负对数，本书按有效目标统计 | 06、08 |
| perplexity / 困惑度 | 所声明自然对数 NLL 均值的指数，不等于任意总 loss 的指数 | 08 |
| gradient accumulation / 梯度累积 | 先累积多个小批的梯度，再执行一次更新 | 07 |
| microbatch / 小批 | 一次前向/反向处理的样本组，不必等于一次更新覆盖的全部样本 | 07 |
| AMP / 混合精度 | 在合适的计算中使用不同精度，行为受设备和配置影响 | 07 |
| GradScaler | 管理 loss scaling、还原尺度及更新检查的组件 | 07 |
| checkpoint / 检查点 | 某一时刻保存的权重和部分状态；实际字段决定恢复能力 | 07 |
| SFT / 监督微调 | 用带监督的示例塑造模型行为，本项目仍使用自回归训练目标 | 06、08 |
| teacher forcing | 用数据中的正确历史预测后续目标，而不是一直沿模型自己的生成历史前进 | 08 |
| overfitting / 过拟合 | 在训练样本上表现好，却未必能处理独立样本 | 08 |
| DDP | 分布式数据并行，多个进程处理数据并同步相关梯度 | 07 选读 |

## 后训练与视觉

| 术语 | 通俗解释 | 首次主讲 |
|---|---|---|
| MoE / 混合专家 | 为每个 token 选择部分前馈子网络，并合并结果 | 09 |
| router / 路由器 | 给专家打分并参与选择的组件，不预先知道人工任务类别 | 09 |
| auxiliary loss / 辅助损失 | 主目标之外的附加目标，需追踪是否真正加到训练 loss 中 | 09 |
| LoRA / 低秩适配 | Low-Rank Adaptation；用低秩矩阵乘积表示参数增量的方法；本地实现无显式 alpha/r | 10 |
| rank / 秩 | 矩阵独立方向的数量；低秩增量容量受到 r 限制 | 10 |
| adapter / 适配器 | 新增的小模块的泛称，不一定都是可以线性合并的 LoRA | 10 |
| distillation / 蒸馏 | 让学生学习教师提供的目标或分布；本书此处为 logits 分布 | 10 |
| KL divergence / KL 散度 | 比较概率分布的非对称量，必须说明方向及估计方式 | 10～12 |
| DPO / 直接偏好优化 | Direct Preference Optimization；根据偏好对直接优化策略相对参考的倾向 | 11 |
| policy / 策略 | 给定历史时产生动作或下一个 token 的分布 | 11～12 |
| reference policy | 固定参考分布，不等于采样批次的 old policy | 11～12 |
| reward / 奖励 | 对生成结果给出的训练信号，取决于模型或规则定义 | 12～13 |
| critic / 价值模型 | 估计前缀回报的组件，不能与奖励模型混为一谈 | 12 |
| advantage / 优势 | 相对某个基准衡量结果好坏的更新信号 | 12 |
| GAE / 广义优势估计 | 用时间差误差递推形成优势的方法 | 12 |
| PPO / 近端策略优化 | 使用旧/新策略比值等构造受约束更新目标的一类方法 | 12 |
| GRPO / 组相对策略优化 | 用同题多回答的奖励形成组内优势，省去此处的 critic | 12 |
| CISPO | 截断重要性权重并对该系数停止求导的策略目标；本地分支有额外约定 | 12 |
| rollout / 采样轨迹 | 策略试做任务并记录 token、概率和观察的过程 | 12～13 |
| observation / 观察 | 工具或环境提供的内容，可输入模型但不应冒充模型自己的动作 | 13 |
| patch | 图像中按编码器配置组织的一块像素区域 | 14 |
| vision encoder / 视觉编码器 | 把像素计算成视觉表征的网络 | 14 |
| projector / 投影模块 | 把一种特征空间映到另一种维度/坐标的连接模块 | 14 |
| freeze / 冻结 | 不更新指定参数，不自动等于跳过前向或永久保持 eval 模式 | 15 |
| Parquet | 支持列式组织的数据文件格式，本项目可同时存对话与图片字节 | 15 |

## 音频与实时交互

| 术语 | 通俗解释 | 首次主讲 |
|---|---|---|
| waveform / 波形 | 随时间记录的振幅采样序列，不等于模型 token | 16 |
| sampling rate / 采样率 | 每秒采样点数，改变标签不等于完成重采样 | 16 |
| PCM | 直接表示采样值的方式，传输时需约定位宽、通道与采样率 | 16、20 |
| resampling / 重采样 | 按新采样率生成表示同一时间范围的采样点 | 16 |
| acoustic feature / 声学特征 | 前端从音频窗口计算的连续描述，与波形点数不同 | 16 |
| Thinker | 当前 Omni 中的语言主干别名，可接收注入的多模态特征 | 17 |
| Bridge | 指定中间位置送到 Talker 的条件状态 | 17 |
| Talker | 根据语义、声学历史与音色条件预测码本的分支 | 17 |
| speaker embedding | 音色条件向量，不是参考音频的完整码本序列 | 17 |
| codec / 编解码器 | 在波形与压缩表示之间转换的组件 | 18 |
| codebook / 码本 | 离散编号及其对应表征的集合，多路可描述同一帧 | 18 |
| delay pattern | 将不同码本通道按时间错开，再按规则恢复帧对应 | 18 |
| T2A / A2A / I2T | 文本到音频、音频到音频、图像到文本等任务缩写 | 19 |
| VAD / 语音活动检测 | Voice Activity Detection；判断是否有语音活动，不负责识别文字 | 20 |
| ASR / 自动语音识别 | Automatic Speech Recognition；把语音转成文字，可能只在特定输入或历史路径中使用 | 20 |
| barge-in / 语音打断 | 播放或生成期间用户重新开口，触发停止旧回复的交互 | 20 |
| flush / 尾部补发 | 正常结束时处理尚不足一块的数据，打断时不应盲目补发旧回复 | 20 |

遇到一个词有不同含义时，先明确所在层次。例如“解码”既可能指 token 到文字，也可能指自回归推理阶段；
“mask”既可能影响注意力，又可能影响 loss。回到它实际作用的张量，比只记中文译名更可靠。
