# 阅读指南：把问题带到代码里

你不需要先读完所有大模型论文。先挑一个能观察的问题：一句话怎样成为整数？
模型怎样为下一个词打分？为什么 loss 能推动参数变化？每解决一个问题，就多掌握一段真实调用链。
本书把文本模型作为基础，再带你走向偏好优化、视觉、音频与实时交互。

## 怎样读一个章节

第一遍读问题、例子和图后的说明，建立方向感。第二遍带着输入输出形状读核心代码，
遇到一个变量就问“它从哪里来，接下来交给谁”。第三遍运行小实验，主动改一个维度或边界输入，
确认自己的预测。不要以能背出类名作为已经理解的标志。

图中的箭头有明确含义：流程图追执行步骤，结构图追组成，时序图追不同参与者的消息。
每张图附读图说明，告诉你第一遍应追哪条线。数学公式旁边会解释符号及其对应的代码，
复杂计算先用小数字走一遍。公式不是装饰，而是压缩后的计算说明书。

## 本书的实验分层

教学例子使用小张量和合成数据，让 CPU 也能看清运算。真实源码实验则导入锁定版本的实现，
检查输出、梯度与边界。完整训练和质量评估需要额外权重、数据及设备，另行标明。
随机权重小模型即使运行成功，也不会突然获得对话能力。

书稿仓库根目录是命令的默认工作目录；上游源码根目录默认为相邻的 `minimind_resources`，
其中包含 `minimind`、`minimind-v`、`minimind-o`。也可设置 `MINIMIND_SOURCE_ROOT` 指向自己的位置。
正式章节给出仓库、文件、符号和固定 commit 链接，即使没有作者电脑也能查到对应实现。

配套环境采用 Python 3.12。安装入口和锁定依赖保存在仓库的 `requirements-book.lock`；
创建虚拟环境后安装它，再运行各章脚本。首次安装需要网络，模型骨架实验本身不下载权重。

```bash
python3.12 -m venv .venv
.venv/bin/python -m pip install -r requirements-book.lock
.venv/bin/python experiments/ch03_model_skeleton.py
```

锁定文件包含本书实验与出版 Python 依赖，不等于三个上游项目的全部训练依赖。
视觉和音频环境会在对应章节说明。不要直接运行上游整套训练脚本来检查一个归一化公式。

## 统一符号

| 符号 | 含义 | 一个小例子 |
|---|---|---|
| $B$ | 一批样本数 | 同时处理两句话时为 2 |
| $S$ | 文本序列长度 | 四个 token 时为 4 |
| $D$ | 每个位置的隐藏维度 | 教学模型可取 32 |
| $V$ | 词表大小 | 小实验可取 32，默认模型为 6400 |
| $I$ | 前馈中间宽度 | 小实验可取 64 |
| $H_q,H_{kv}$ | 查询头数、键值头数 | 小实验取 4 和 2 |
| $d_h$ | 每个注意力头的维度 | 32 除以 4 得到 8 |
| $T_a$ | 音频时间帧数 | 与文本 token 数分开计数 |

形状 `(B,S,D)` 是三个轴的长度。它告诉你数值如何组织，不直接告诉你语义是否正确。
dtype 表示数值类型，如整数 ID 或 FP32 浮点数；device 表示数据放在 CPU 还是其他设备上。
遇到形状相容但结果奇怪时，还要检查索引、归约轴、mask 和时间位置。

## 对验证范围的约定

“源码事实”可以在固定版本里直接找到；“实验观察”仅适用于记录的配置；
“作者说明”表达上游报告的意图；“推断”会公开推导依据。不能验证的性能或质量结论不编造数字。
电子书中的公式和图源来自同一份 Markdown，排版转换也要经过内容对照。

这份指南与后续章节共同组成书稿。预览版会明确实际收录范围，不把尚未写完的目录当作正文。
